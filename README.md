# AI Agent Course · Interactive Study Notes

[English](#english) · [中文](#中文)

**Live site: <https://xinshuer.github.io/agent-course/>**

<a id="english"></a>

A bilingual (English / Chinese) interactive study site for the Bilibili course “Agent 智能体开发全套教程” (BV1YG7G6eEPR, 59 episodes): notes for every lesson, quizzes, fill-in-the-code and write-it-yourself exercises, Python you can run in the browser, and local practice files that call a real model (DeepSeek).

> **Note**: these are unofficial personal study notes, not affiliated with the course author. The videos belong to their author; watch the original course on Bilibili: <https://www.bilibili.com/video/BV1YG7G6eEPR/>. This repository contains no video, subtitles or original course materials: the notes are written in our own words, and the practice code was rewritten for the framework versions in `requirements*.txt`.

## Opening the site

Use the live site above, or open `index.html` locally in Chrome or Edge (double-click; no server needed).

- Progress, quiz answers and your drafts are saved in your browser (localStorage). They are lost if you switch browsers or clear site data.
- The ▶ Run buttons use Python in the browser (Pyodide, downloaded on first use). Code that calls a model talks to a **mock model** there: offline, free, no API key.
- Switch languages with the **EN / 中文** button in the top-right corner.

## Running the practice files

First create the two virtual environments (Python 3.12; run in the project folder):

```powershell
py -3.12 -m venv .venv
& .venv\Scripts\python.exe -m pip install -r requirements.txt
py -3.12 -m venv .venv-crewai
& .venv-crewai\Scripts\python.exe -m pip install -r requirements-crewai.txt
```

Then run exercises from the `practice` folder:

```powershell
cd practice
& ..\.venv\Scripts\python.exe l06_chat.py
# CrewAI (lessons 51–58)
& ..\.venv-crewai\Scripts\python.exe l51_xxx_solution.py
```

The API key is read from the user environment variable `DEEPSEEK_API_KEY` (see `practice/llm.py`); it is never written in code. Set it with `setx DEEPSEEK_API_KEY "your-key"`, then reopen your terminal or VS Code. On macOS / Linux use `python3.12`, `.venv/bin/python` and `export DEEPSEEK_API_KEY=...`. The site's Setup page has the full steps.

## Maintenance commands

Run in the project folder (needs Node.js; any Python 3 works for `python`):

```powershell
node tools/validate.js --export build/code.json          # check the lesson data (every field needs zh and en)
python tools/check_code.py build/code.json               # compile and run the lesson code on the mock (both languages)
node tools/check_sources.js                              # timestamp links valid, notes not copied from subtitles
node tools/en_fields.js lint all                         # zh/en in sync (links, list shape, inline code, code logic)
python tools/build_pyfiles.py                            # re-bundle after editing assets/py/*.py
```

After changing a lesson's Chinese, export the zh/en pairs with `node tools/en_fields.js dump lNN`, write the updated English as JSON `{"field path": "English"}`, and write it back with `node tools/en_fields.js apply lNN <file>.json`.

## About the content

The notes were checked against each episode's Bilibili AI subtitles (used only as a reference and kept locally by the maintainer, not in this repository; the subtitle check in `check_sources.js` is skipped without them), and the code against the framework versions in `requirements*.txt`. Where this course differs from the video, the notes say so.

## 运行练习

先创建两个虚拟环境（需要 Python 3.12，在项目文件夹里运行）：

```powershell
py -3.12 -m venv .venv
& .venv\Scripts\python.exe -m pip install -r requirements.txt

& .venv-crewai\Scripts\python.exe -m pip install -r requirements-crewai.txt
```

然后进入 `practice` 运行练习：

```powershell
cd practice
& ..\.venv\Scripts\python.exe l06_chat.py
```

API key 从用户环境变量 `DEEPSEEK_API_KEY` 读取（见 `practice/llm.py`），代码里不写 key。设置方法：`setx DEEPSEEK_API_KEY "你的key"`，设置后重新打开终端或 VS Code。macOS / Linux 用 `python3.12`、`.venv/bin/python` 和 `export DEEPSEEK_API_KEY=...`。详细步骤见网站的「环境准备」页。

## 维护命令

在项目文件夹里运行（需要 Node.js；`python` 用任意 Python 3 即可）：

```powershell
node tools/validate.js --export build/code.json          # 检查讲义数据格式（每个字段都要有中英文）
python tools/check_code.py build/code.json               # 编译并在模拟模型上运行讲义代码（中英两版）
node tools/check_sources.js                              # 时间戳链接是否有效、讲义是否照抄了字幕
node tools/en_fields.js lint all                         # 中英文是否同步（链接、列表结构、行内代码、代码逻辑）
python tools/build_pyfiles.py                            # 修改 assets/py/*.py 后重新打包
```

改了某一节的中文以后，用 `node tools/en_fields.js dump lNN` 导出中英对照，把要更新的英文写成 `{"字段路径": "英文"}` 的 JSON，再用 `node tools/en_fields.js apply lNN <文件>.json` 写回。
