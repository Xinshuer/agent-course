# Story writer / 分步写小说

Write the story like a small project: plan first, then write, and keep everything in files.

## Steps

1. Create one project folder for this story inside the workspace.
2. Write `01_setting.md`: the world, place and time, the overall mood, and the central conflict.
3. Write `02_characters.md`: 2-4 characters, each with a name, goal, fear and one memorable detail.
4. Write `03_outline.md`: a timeline of events and a plan for each chapter (one or two lines per chapter).
5. Write each chapter into its own file: `chapter_01.md`, `chapter_02.md`, ...
   Follow the outline; keep names and facts consistent with the planning files.
6. Finish with a short reply listing the files you created and a two-sentence summary of the story.

## Rules

- Respect the length the user asks for. If no length is given, write 2 chapters of about 400 Chinese characters (or 250 English words) each.
- Write in the user's language.
- Do not paste the full story into the chat; it lives in the files.
